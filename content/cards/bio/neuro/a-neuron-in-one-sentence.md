# A spiking neuron, in one useful sentence

It gathers signals, and when the result is strong enough, it can send a pulse down its axon.

For many neurons, branches called dendrites receive signals that raise or lower the chance of firing. An action potential travels along the axon and can trigger chemical release at its terminals. Stronger input often changes the *rate or timing* of pulses more than the size of an individual pulse.

That sentence is a model, not a complete job description. Dendrites can process inputs locally rather than simply add them. Some neurons, including many retinal bipolar cells, communicate mainly through graded voltage changes instead of ordinary action potentials.

Q: In a typical spiking neuron, how can stronger input alter the output?
- [x] It can change the rate or timing of action potentials — individual spikes are relatively stereotyped, while spike trains vary.
- [ ] It must make each action potential proportionally taller — spike amplitude is not the usual strength code.
- [ ] It makes the axon grow more dendrites immediately — dendrites receive input and do not resize in response to each stimulus.
- [ ] It prevents any chemical release at terminals — arriving action potentials can promote transmitter release.
