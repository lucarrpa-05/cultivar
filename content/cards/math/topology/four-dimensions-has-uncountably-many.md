# Four dimensions has uncountably many calculuses

On $\mathbb{R}^n$ there is exactly one smooth structure — one consistent verdict on which functions are differentiable — for every $n$ except one. On $\mathbb{R}^4$ there is a continuum of them, pairwise non-diffeomorphic, every one homeomorphic to the ordinary $\mathbb{R}^4$.

The first came in 1982, from Freedman's classification of topological 4-manifolds run against Donaldson's gauge theory; Taubes showed in 1987 that there are uncountably many. Other dimensions have exotic *spheres* — Milnor found seven-dimensional ones in 1956 — but $\mathbb{R}^4$ is the only Euclidean space where topology and calculus come apart.

## Recall
type: reveal
Q: What does "exotic $\mathbb{R}^4$" mean, exactly?
A: A smooth manifold homeomorphic to $\mathbb{R}^4$ but not diffeomorphic to it: the same open sets and the same continuous maps, an incompatible verdict on which maps are smooth. Only dimension four has them.
